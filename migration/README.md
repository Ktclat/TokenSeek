# 迁移 0.9.2 及更早版本的本机数据

普通原生版只读取自己的 SQLite 数据库。需要保留旧版聊天、未发送草稿、附件、项目、账户头像或设置时，在**同一 Android 用户、同一台设备**上依次操作。

1. 直接覆盖安装与原版签名相同的迁移 APK，并打开「TokenSeek 旧版迁移」。安装期间保留应用数据。
2. 点「准备迁移」，等到页面显示已准备的账户及对话数。
3. 直接覆盖安装原生版，打开 TokenSeek 并合并已准备的旧数据。合并优先保留同 ID 的本机对话和已有的设置。请勿在两个安装步骤之间卸载应用或清除数据。

迁移工具使用与当前原生版相同的包名和版本码。本版为 versionCode 14，适用于 0.10.1。已经安装原生版时也可以先覆盖为同签名、同版本码的迁移工具，再覆盖回原生版。设备安装器如不允许相同版本覆盖，Android 调试桥支持对两个 APK 分别执行 `adb install -r /path/to/app.apk`。

迁移版独立运行，无网络权限。它在旧聊天客户端的应用内来源读取列出的账户、聊天 IndexedDB 和白名单偏好，逐块复制到应用私有目录并校验 SHA-256。迁移版不会读取平台网页会话、Cookie 或 API 密钥，KeyStore 密钥沿用原来的账户 ID。中断时可以重试，旧浏览器数据库会保留。只需已导出的聊天时，可直接在原生版「数据管理」合并原有 ZIP。

## 构建迁移版

运行 `migration/build-exporter.sh /path/to/0.9.2-checkout /path/to/TokenSeek-legacy-migration.apk`。这会用旧仓库的 Gradle 配置，在临时独立模块里打包迁移界面。默认构建 debug APK，需使用与本机已安装 APK 一致的签名。发布签名不同的自建版本应使用自己的原签名。原生主应用不引用迁移界面及其浏览器代码。
